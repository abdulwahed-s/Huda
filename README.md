## 🚀 Quick Start

### Prerequisites

* **Flutter SDK:** `3.6.2` or higher
* **Dart SDK:** `3.6.2` or higher

### Installation

#### 1. Clone the repository

```bash
git clone https://github.com/abdulwahed-s/Huda.git
cd Huda
```

#### 2. Install dependencies

```bash
flutter pub get
```

#### 3. Configure Firebase *(Optional but Recommended)*

1. Create a Firebase project and register your applications.
2. Place `google-services.json` inside:

```text
android/app/
```

3. Place `GoogleService-Info.plist` inside:

```text
ios/Runner/
```

4. Configure your API keys in:

```text
lib/core/keys/hadith_key.dart
```

For more information, see:
https://github.com/abdulwahed-s/Huda/issues/1

#### 4. Run the application

```bash
flutter run
```

## 🌟 Key Features

### 📖 Quran Reading & Study

* Complete Quran with authentic Uthmanic script
* Multiple translations and Tafsir support
* Audio recitations with offline playback
* Smart reading position tracking

### 🕌 Prayer Times & Adhan

* Accurate location-based prayer times
* Adhan notifications and countdown timers
* Multiple calculation methods

### 🧭 Qiblah Compass

* Accurate Qiblah direction
* Smooth animations with haptic feedback

### 📿 Digital Tasbih

* Persistent Dhikr counter
* Notes and tracking support

### 🤲 Athkar & Duas

* Categorized daily supplications
* Audio pronunciation support

### ✅ Islamic Daily Checklist

* Track prayers and habits
* Hijri calendar integration
* Daily streak tracking

### 🤖 Huda AI Assistant

* AI-powered Islamic Q&A assistant
* Responses based on authentic Sunni sources, Quran, and Hadith

### 📚 Hadith & Islamic Library

* Curated Islamic books and Hadith collections
* Built-in offline PDF reader

### 📱 Home Screen Widgets

* Quick access to prayer times and core features

### 🌍 Multilingual Support & Themes

* RTL Arabic support
* Dynamic language switching
* Dark and Light themes
